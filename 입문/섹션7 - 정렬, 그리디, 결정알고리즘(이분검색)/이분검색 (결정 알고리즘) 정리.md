# 이분검색 (결정 알고리즘) 정리
이분 검색과 결정 알고리즘은 자주 함께 사용되는 개념이다.

## 이분 검색과 결정 알고리즘의 관계
이분 검색 + 결정 알고리즘 = 최적값 찾기

### 이분검색
- 탐색 기법이다.
- 정렬된 범위에서 탐색 공간을 반씩 줄여가며 값을 찾는다.
- left, right, mid 를 활용
- O(log N)

### 결정 알고리즘
- 문제의 형태이다.
- 어느 조건을 만족하는가? 를 판단하는 문제.

### 이분 검색 예제

```JavaScript
let target = 5;

// 탐색 범위: 가능한 답의 범위
let left = 1;
let right = 10;

// 조건을 만족하는 최소값
let result = 0;

while (left <= right) {
  // 범위의 중간값
  let mid = Math.floor((left + right) / 2);
  
  // 판별: mid 가 조건을 만족하는가?
  if (mid >= target) {
    answer = mid;
    right = mid - 1; // 더 작은 값도 가능한가?
  } else {
    left = mid + 1; // 아직 조건을 만족하지 못함 → 범위 증가
  }
}

console.log(answer); // 5
```
